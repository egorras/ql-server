## Regenerating this table

Run on the server, after the workshop items have downloaded at least once (check `steamapps/workshop/content/282440/`):

```sh
python3 -c "
import zipfile, os
base = '/home/ubuntu/ql-server-data/qlds/steamapps/workshop/content/282440'
for d in sorted(os.listdir(base), key=int):
    dirpath = os.path.join(base, d)
    for f in os.listdir(dirpath):
        if f.lower().endswith('.pk3'):
            with zipfile.ZipFile(os.path.join(dirpath, f)) as z:
                bsps = [n for n in z.namelist() if n.lower().startswith('maps/') and n.lower().endswith('.bsp')]
            names = [os.path.splitext(os.path.basename(b))[0] for b in bsps]
            print(d, f, ','.join(names) or 'NO BSP FOUND')
"
```
